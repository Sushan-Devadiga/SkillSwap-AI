# SkillSwap AI - Site Architecture

## Core Flow
- **Splash (01)**: Logo and tagline.
- **Onboarding (02-04)**: Introduces teaching, learning, and AI matching.
- **Auth (05-07)**: Login, Signup, Forgot Password.
- **Profile Setup (08-11)**: Bio, Teaching Skills, Learning Skills, Availability.
- **Home (12)**: Dashboard, quick actions, matches.
- **Discover (13)**: Search skills and people.
- **AI Matches (14)**: List of AI-recommended partners.
- **Match Details (15)**: Compatibility score and explanation.
- **Public Profile (16)**: User's public details and reviews.
- **Swap Request (17-18)**: Request flow and status.
- **Chat (19-20)**: Conversations and realtime messaging.
- **AI Assistant (21)**: Learning plans and quiz generation.
- **Scheduling (22-24)**: Calendar, sessions, session details.
- **Learning (25-28)**: Progress, journey, ratings, certificates.
- **Community (29-31)**: Posts, comments, leaderboard.
- **Notifications & Settings (32-35)**: Alerts and user config.
